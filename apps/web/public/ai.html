Try it now — free, no signup

Copy this URL into your AI assistant’s connector settings (see the setup steps below) — it’s a server address for your assistant to call, not a page to open in your browser, so visiting it directly won’t show anything useful. Once connected, it gives your assistant tools to draft chase emails, get tone tips, and recommend templates.

https://api.docstoc.io/mcp

Nothing is ever emailed or changed through MCP — every tool here is draft-only / read-only.

Claude (claude.ai or the desktop app)

Set up: Settings → Connectors → Add custom connector → paste the URL above, authentication “None”.

Use it: Click the “+” at the bottom-left of the chat box → Connectors → make sure docstoc is toggled on for that conversation. Then ask naturally — e.g. “draft a chase email for Acme, $1,200, 12 days overdue.”

ChatGPT

Set up: Settings → Security and login → turn on Developer Mode. Then Settings → Connectors (or Plugins) → Add custom connector → paste the URL above.

Use it: Pick it from the Tools menu (the “+”/tools icon in the message box), or type “@docstoc” followed by your request.

Grok

Set up: Available on Grok’s paid tiers. Click the “+” in the chat box → Connectors → New Connector → Custom → paste the URL above.

Use it: Just ask your question normally once it’s added — Grok calls the tool automatically when it’s relevant.

Perplexity

Set up: Requires a Pro or Max plan. Settings → Connectors → Add custom connector → paste the URL above, authentication “None”.

Use it: Reference it directly in your question — mentioning “docstoc” or asking to draft an invoice follow-up is usually enough.

IDE / agent clients — configs

Formats differ by client. Cursor and Claude Code use an mcpServers JSON file; ChatGPT and Grok take the server URL in their connector UI (same endpoint as above).

Cursor / Claude Code mcpServers JSON

Add this to your client’s MCP config file (Cursor’s .cursor/mcp.json, Claude Code’s .mcp.json): 

{
{
  "mcpServers": {
    "docstoc": {
      "url": "https://api.docstoc.io/mcp"
    }
  }
}

Some clients want a "type": "http" field alongside "url" — check your client’s MCP docs if this doesn’t connect right away.

ChatGPT connector URL

ChatGPT does not use mcpServers JSON. Enable Developer Mode (Settings → Security and login), then Settings → Connectors (or Plugins) → Add custom connector and paste: 

https://api.docstoc.io/mcp

Authentication: None. In a chat, pick docstoc from the Tools menu (or type “@docstoc”).

Grok connector URL

Grok’s chat UI is URL-based (not mcpServers JSON). On a paid tier: click “+” in the chat box → Connectors → New Connector → Custom, or open grok.com/connectors, and paste: 

https://api.docstoc.io/mcp

Once added, ask normally — Grok calls the tool when it’s relevant. Grok’s CLI / agent tooling can also reuse the Cursor mcpServers JSON above (or a ~/.grok/config.toml entry with the same URL).
